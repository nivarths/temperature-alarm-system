# Temperature Alarm System  
An Arduino-based system that uses a DHT11 sensor to monitor temperature and trigger a buzzer alarm if a threshold is exceeded.

## Features  
- Real-time temperature monitoring with DHT11  
- Threshold-based buzzer activation  
- Serial Monitor output for debugging and live readings  
- Configurable temperature limit

## Tech Stack  
- Arduino UNO R3  
- C++ (Arduino IDE)  
- DHT11 Temperature Sensor  
- Passive Buzzer  
- Breadboard + jumper wires

## Skills  
- C++ programming
- Sensor integration and data reading  
- Threshold-based logic control  
- Serial communication debugging  
- Basic circuit wiring and prototyping
